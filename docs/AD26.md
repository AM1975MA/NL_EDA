## Procedure

1. Run `Build-AD26.ps1` on the Windows host; inspect all compiler and XAML errors.
2. Resolve reference/version mismatches and confirm the plugin's target framework matches the AD26 host; DevExpress 25.2 references alone do not prove this.
3. Avoid putting Altium / DevExpress DLLs under version control; compile only against the licensed local installation.
4. Perform a test installation only after a valid build, preferably on non-production/VM.
5. Explicitly identify the active AD26 extension registry. The user's Preferences path GUID is a **data path**, not proof of the extension install GUID.
6. Back up the current `ExtensionsRegistry.xml` and any existing plugin folder, then devise a reversible target-specific installer.
7. Open a SchDoc to test that the menu item appears. Import a known LCSC component such as C2040 and verify SchLib, PcbLib, pin-to-pad correspondence and STEP transform.

**Upstream `All.ps1` / `Deploy.ps1` are disabled in this branch.** The original auto-discovery can select the wrong installation when multiple Altium profiles exist.

Known upstream issues: [AD26 menu/startup](https://github.com/expired6978/EasyEDALoader/issues/5) and [3D origin](https://github.com/expired6978/EasyEDALoader/issues/8).

## Controlled installer preflight

`Manage-AD26.ps1` uses explicit tested workstation paths, defaults to read-only `Status` and refuses installation/removal without `-Apply`. Install and uninstall are refused whenever an `X2.exe` process is running. It makes a new SHA256-verified backup of the exact current registry before changes; if installation fails it attempts immediate rollback. For emergencies, the backup contains `Manage-AD26.ps1` and `ExtensionsRegistry.xml` and can be restored manually.

The script has **not yet been executed on the target PC**, nor has the AD26 extension been loaded. Successful compilation with 0 errors and warnings is independent of runtime deployment compatibility.

## UI revision & upgrade gate

The first EasyEDA Loader search view showed the symbol on a black background and its `Add to Library` button remained disabled (none of the first-column `AddToLibrary` checkboxes was selected). The revised XAML enables grid checkbox editing, adds an explicit `Select current` toggle and LCSC code column, shows selected-count feedback, sorts exact LCSC matches first, and uses a white schematic preview with darker shapes. PCB preview retains its black background and layer colors. The `Place last imported part in schematic` checkbox is not an import command; actual import requires `Add to Library` with >=1 selected part.

Use `-Action Upgrade -Apply` for already installed versions: it backs up the entire previous plugin and the registry, hashes copies, modifies no registration, and attempts verified restoration of previous binaries on failure. **It has not yet been tested on the target user's machine; build before upgrade.**
